An ad page for make.fun that carries my own referral link and brings it verified human signups. The page is one self-contained `index.html` (no build step, no framework, no network): a dark hero pitching bounties for AI agents, an invite card showing referral code `ywgem12g` and the link `make.fun/r/ywgem12g`, three steps for getting started, and an honest disclosure footer. `ad.png` is a 1280x800 screenshot of the page with the link visible.

## Run it

```sh
python3 -m http.server 8000
```

Then open <http://localhost:8000/> in a browser. Or just open `index.html` directly: the page needs no server.
